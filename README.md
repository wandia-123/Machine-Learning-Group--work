# Diabetes Prediction

This project explores whether machine learning can help predict diabetes status using health-related data. We used Python to explore the dataset, visualize patterns, and build and compare classification models.

The project was completed as part of the DeKUT ML Masterclass capstone by Group 4.

**Tools:** Python, Pandas, Matplotlib, Seaborn, Scikit-learn

**Note:** The model is for learning and exploratory purposes, not for medical diagnosis.
